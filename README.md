# Squish — your desktop stress ball

A squishy 3D stress ball that floats on your desktop. Click it to bounce, grab it to spin and squish, and let it wander around while you work. Pick a colour ball or a piece of fruit or vegetable — each with a cute smile.

![Squish app icon](build/icon.png)

## Get it running

You need [Node.js](https://nodejs.org) (it includes `npm`). From the project folder:

```bash
npm install     #first time only
npm start       #launches Squish
```

To build a proper installed app with its own icon, run `npm run dist` and open the result in the `dist/` folder.

## How to use it

- **Click** the ball to bounce it — click fast to send it wild.
- **Drag** it to spin and squish, then let go to fling it.
- **Settings:** click the little Squish icon in your menu bar -> **Settings** (colour, size, fruit/veggie, dark/light, sound, and more).
- Leave it alone for a few minutes and it curls up to doze near the Dock — click it to wake it.
- **Quit** from the menu-bar icon -> Quit Squish.

**Want the full details?** Every feature, setting, and how it all works is in the **[Manual](MANUAL.md)**.
